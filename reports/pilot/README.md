# Số liệu chạy thử (mô hình điểm)

Chỉ đưa vào đây những gì **đã ẩn tên**: nhật ký tuần do `sudo onebee-box bao-cao-tuan` sinh ra (không có tên người báo,
nội dung mô tả, góp ý) + phần kỹ thuật ghi tay, số đo trước/sau (`reports/do-dac/`), báo cáo cuối.
**Không** đưa: file CSV gốc trên Box (`/srv/onebee/ho-tro/`), file của người dùng, tên khách hàng, số liệu kế toán.

| File | Nội dung |
|---|---|
| `nguong-dat.md` | Ngưỡng "đạt" — anh chốt TRƯỚC khi bắt đầu |
| `nhat-ky-tuan-1.md` … `nhat-ky-tuan-4.md` | Nhật ký hằng tuần |
| `bao-cao-pilot.md` | Báo cáo cuối, theo `mau-bao-cao-pilot.md` |

Quy trình: [docs/huong-dan/chay-thu-tai-don-vi.md](../../docs/huong-dan/chay-thu-tai-don-vi.md).
