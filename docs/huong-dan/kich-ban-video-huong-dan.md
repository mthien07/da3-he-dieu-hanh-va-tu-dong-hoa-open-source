# Kịch bản 5 video hướng dẫn ngắn (quay khi chạy thử trên máy thật)

Mỗi video 1–3 phút, quay màn hình thật (phiên Cinnamon, dữ liệu mẫu — **không** quay file, tên, email thật của đơn vị),
có lồng tiếng tiếng Việt, phụ đề. Quay xong: kiểm từng bước khớp phiên bản đang cài, ghi phiên bản vào mô tả video.

| # | Tên | Nội dung (theo thứ tự quay) | Kết thúc bằng |
|---|---|---|---|
| 1 | Làm quen OneBee OS | Bắt đầu từ cửa sổ **Trung tâm OneBee** (tự mở ở lần đăng nhập đầu; mở lại từ menu Bắt đầu) → menu góc trái / phím Super → mở Firefox, LibreOffice Writer, thư mục cá nhân → ghim ứng dụng ra thanh tác vụ → tắt máy | Tờ phím tắt |
| 2 | Gõ tiếng Việt | Super + Space đổi Việt/Anh → gõ Telex câu "Hợp tác xã OneBee báo cáo quý III" → sửa dấu (z) | Dòng chữ gõ đúng |
| 3 | Word/Excel và PDF | Mở .docx mẫu → sửa → Ctrl+S (vẫn là .docx) → thẻ File → Export Directly as PDF → mở .xlsx, SUM → lưu | File PDF mở được |
| 4 | Trợ lý AI | Bấm biểu tượng "Trợ lý AI OneBee" trên thanh tác vụ → soạn thông báo họp (có [chỗ điền]) → nhắc: đọc lại số liệu, không dán mật khẩu | Văn bản nháp |
| 5 | Cần giúp? | **Trung tâm OneBee → Cần giúp đỡ** (hoặc menu "Báo cần hỗ trợ") → chọn loại → gửi → mã yêu cầu. Trang **Kiểm tra máy** → "Kiểm tra ngay" → đọc kết quả → gửi kèm yêu cầu hỗ trợ. Menu "Cho phép hỗ trợ từ xa" → đọc mã → bấm Cho phép → Dừng. Lỡ xóa file → báo loại "Sao lưu / mất file" | Nhắc: không bấm cho người lạ |
