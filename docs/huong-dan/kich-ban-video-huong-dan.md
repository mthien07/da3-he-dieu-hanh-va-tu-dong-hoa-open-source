# Kịch bản 5 video hướng dẫn ngắn (quay khi chạy thử trên máy thật)

Mỗi video 1–3 phút, quay màn hình thật (phiên Cinnamon, dữ liệu mẫu — **không** quay file, tên, email thật của đơn vị),
có lồng tiếng tiếng Việt, phụ đề. Quay xong: kiểm từng bước khớp phiên bản đang cài, ghi phiên bản vào mô tả video.

| # | Tên | Nội dung (theo thứ tự quay) | Kết thúc bằng |
|---|---|---|---|
| 1 | Làm quen OneBee OS | Menu góc trái / phím Super → mở Firefox, LibreOffice Writer, thư mục cá nhân → ghim ứng dụng ra thanh tác vụ → tắt máy | Tờ phím tắt |
| 2 | Gõ tiếng Việt | Super + Space đổi Việt/Anh → gõ Telex câu "Hợp tác xã OneBee báo cáo quý III" → sửa dấu (z) | Dòng chữ gõ đúng |
| 3 | Word/Excel và PDF | Mở .docx mẫu → sửa → Ctrl+S (vẫn là .docx) → nút PDF → mở .xlsx, SUM → lưu | File PDF mở được |
| 4 | Trợ lý AI | Mở `http://<ip-box>:3000` → "Trợ lý OneBee" → soạn thông báo họp (có [chỗ điền]) → nhắc: đọc lại số liệu, không dán mật khẩu | Văn bản nháp |
| 5 | Cần giúp? | Menu "Báo cần hỗ trợ" → chọn loại → gửi → mã yêu cầu. Menu "Cho phép hỗ trợ từ xa" → đọc mã → bấm Cho phép → Dừng. Lỡ xóa file → báo loại "Sao lưu / mất file" | Nhắc: không bấm cho người lạ |
