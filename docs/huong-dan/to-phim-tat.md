# Tờ phím tắt OneBee OS (in khổ A4, dán cạnh màn hình)

> Kỹ thuật: kiểm lại từng dòng trên máy thật của đơn vị trước khi in (chưa kiểm trên phiên Cinnamon thật).

| Việc | Phím / cách làm |
|---|---|
| Đổi gõ tiếng Việt ⇄ tiếng Anh | **Super + Space** (Super = phím có logo Windows) |
| Gõ Telex | aa=â, aw=ă, ee=ê, oo=ô, ow=ơ, uw=ư, dd=đ · s=sắc, f=huyền, r=hỏi, x=ngã, j=nặng · z=xóa dấu |
| Mở menu Bắt đầu | Phím **Super** (hoặc bấm nút **Bắt đầu** có logo OneBee, góc trái dưới) |
| Chạy lệnh / mở nhanh chương trình (như Run) | **Super + R** (hoặc Alt + F2) |
| Mở thư mục cá nhân (như "Máy tính này") | **Super + E** |
| Hiện màn hình nền / quay lại | **Super + D** |
| Khóa màn hình khi rời máy | **Super + L** (hoặc Ctrl + Alt + L) |
| Chuyển giữa các cửa sổ | **Alt + Tab** |
| Quản lý tác vụ (Task Manager) — xem/tắt chương trình bị treo | **Ctrl + Shift + Esc** |
| Sao chép / Dán / Cắt / Hoàn tác | Ctrl + C / Ctrl + V / Ctrl + X / Ctrl + Z (như Windows) |
| Lưu / Lưu thành file khác / In | Ctrl + S / Ctrl + Shift + S / Ctrl + P |
| Xuất PDF (Writer, Calc) | Nút **PDF** trên thanh công cụ |
| Kiểm tra chính tả | **F7** |
| Chụp màn hình | Phím **Print Screen** |
| Chụp một vùng màn hình vào clipboard (như Snipping Tool) | **Super + Shift + S** → kéo chuột chọn vùng → dán bằng **Ctrl + V** (Shift + Print Screen: chụp vùng lưu thành file) |
| Mở cửa sổ dòng lệnh (kỹ thuật hướng dẫn) | Ctrl + Alt + T |

| Cần giúp | Làm gì |
|---|---|
| Gặp sự cố | Menu → **"Báo cần hỗ trợ (OneBee)"** → chọn loại, mô tả, Gửi. Gấp: gọi ☎ ____________ |
| Kỹ thuật cần xem màn hình | Menu → **"Cho phép hỗ trợ từ xa (OneBee)"** → đọc địa chỉ + mã → máy hỏi thì bấm **Cho phép** |
| Mở thư mục chung của đơn vị | Biểu tượng **"Chia sẻ nội bộ (OneBee Box)"** trên màn hình nền |
| Lỡ xóa file | Báo hỗ trợ loại "Sao lưu / mất file" — máy tự sao lưu lên Box 12:00 hằng ngày |
| Hỏi Trợ lý AI | Mở trình duyệt: `http://____________:3000` → chọn "Trợ lý OneBee" (AI có thể sai — đọc lại) |

**Không** bấm "Cho phép hỗ trợ từ xa" khi có người lạ gọi điện yêu cầu. Kỹ thuật OneBee không bao giờ hỏi mật khẩu của bạn.
